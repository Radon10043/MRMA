Existing metamorphic relations of Heap Sort Algorithm are shown as follows:

1. Shuffling the elements in the input array, the output will be the same.
2. Adding a constant K to each element in the input array, then each element of the output array will be larger by K than the element at the same location of the original output array.
3. Multiplying -1 to each element in the input array, then if we multiply -1 to each element of the output array, it should be the same as the original output array, but in reverse order.
